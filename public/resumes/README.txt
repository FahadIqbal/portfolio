PLACEHOLDER FILES

The .txt files in this directory are placeholders that should be replaced with actual PDF resume files.

To implement the resume download functionality properly:

1. Replace project-manager-resume.txt with project-manager-resume.pdf (a real PDF file)
2. Replace developer-resume.txt with developer-resume.pdf (a real PDF file)

These files will be served by the application when users click the download buttons in the Contact section.
